STEELWAVE — tienda estática para GitHub Pages

ARCHIVOS
- index.html: estructura y catálogo
- style.css: diseño adaptable a móvil y ordenador
- script.js: navegación entre catálogo y detalle de producto
- assets/: imágenes recortadas de la captura que has enviado

ANTES DE PUBLICAR
1. Cambia "Consultar precio" y "por confirmar" por los precios reales.
2. Sustituye "TELÉFONO: POR COMPLETAR" por el número de pedidos.
3. Reemplaza las imágenes de assets/ por fotos originales de mejor calidad cuando las tengas.
4. Si cambias los nombres de las imágenes, actualiza también las rutas en index.html y script.js.

PUBLICAR EN GITHUB PAGES
1. Crea un repositorio en GitHub.
2. Sube el contenido de esta carpeta (index.html, style.css, script.js y assets/).
3. En Settings > Pages, selecciona Deploy from a branch.
4. Elige la rama main y la carpeta / (root), guarda y espera a que GitHub genere la web.

No necesita servidor, base de datos ni instalación: es HTML/CSS/JS estático.
